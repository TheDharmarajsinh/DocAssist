# DocAssist

DocAssist is a web application designed to streamline the process of booking doctor appointments. It offers a feature-rich, user-friendly platform for patients, doctors, and administrators to manage appointments, profiles, and schedules efficiently.

---

## 🚀 Features

### Admin Panel
- Add, edit, and delete doctor profiles.
- Schedule new doctor sessions or remove existing ones.
- View patient details and their booking history.

### Doctor Portal
- Access and manage scheduled appointments.
- View session schedules and patient details.
- Update profile settings.
- Delete account if needed.

### Patient (Client) Portal
- Create an account and log in securely.
- Book appointments online with preferred doctors.
- Access and review past bookings.
- Update account settings.
- Delete account if desired.

---

## 🛠️ Technologies Used
- **Frontend:** HTML, CSS
- **Backend:** PHP
- **Database:** MySQL

---

## 🔧 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/TheDharmarajsinh/DocAssist.git
   ```
2. Navigate to the project directory:
   ```bash
   cd DocAssist
   ```
3. Set up the database:
   - Import the SQL file located in the `sql/` directory into your MySQL server.
4. Configure database credentials:
   - Update the database configuration in the `php/` files.
5. Start the server:
   - Use a local server environment like XAMPP or WAMP to host the application.
